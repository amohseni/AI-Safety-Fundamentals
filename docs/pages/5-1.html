Universal approximation

Theorem The universal approximation theorem says: a network with one hidden layer, using any continuous activation function that is not a polynomial, can approximate any continuous function on a closed and bounded region as closely as desired, given enough hidden units.Cybenko (1989), “Approximation by superpositions of a sigmoidal function,” Mathematics of Control, Signals and Systems 2: 303–314, for sigmoid activation functions. Hornik (1991), “Approximation capabilities of multilayer feedforward networks,” Neural Networks 4: 251–257. Leshno, Lin, Pinkus, and Schocken (1993), “Multilayer feedforward networks with a nonpolynomial activation function can approximate any function,” Neural Networks 6: 861–867, for the condition that the activation function is not a polynomial.

For ReLU the reason can be seen with one input \(x\). A hidden unit computes \(a\,\mathrm{ReLU}(x - c)\): zero to the left of its kink at \(c\), and a straight line of slope \(a\) to the right of it. The network’s output adds up its units and a constant \(b\),

$$f(x) = b + \sum_{k=1}^{m} a_k\,\mathrm{ReLU}(x - c_k),$$

so the output is a continuous curve made of straight pieces, with a bend wherever a unit has its kink. The tool asks how many units a given curve needs. On this page every function lives on the interval from 0 to 1, and the error is the root mean square distance between the network’s output and the target, over 401 evenly spaced points.

Depth

The target is a sawtooth. The deep network has \(k\) hidden layers of 2 ReLU units each. The shallow network has one hidden layer with the same total number of units, \(2k\), with evenly spaced kinks and slopes fitted by least squares.

  1. The bump target is 0 up to \(x = 0.2\), rises in a straight line to 0.5 at \(x = 0.4\), falls back to 0 at \(x = 0.6\), and stays at 0. What is the smallest number of units that builds it exactly?

    In By hand, choose Bump, add units, and adjust them until the error is 0.

    Three: slopes 2.5, \(-5\), and 2.5, with kinks at 0.2, 0.4, and 0.6. The second unit turns the rise into a fall, and the third cancels the fall, so the bump is two ramps, one subtracted from the other. Each unit adds exactly one bend, and the bump has three, so two units cannot build it: the best two-unit fit has error 0.076. Bumps like this one, placed side by side at the right heights, can trace any continuous curve, which is the idea of the theorem.

  2. Choose the jagged target in Fit. About how many units bring the error below 0.01?

    Move the number of units and watch the error chart.

    About 40: the error first falls below 0.01 at 42 units and stays below for every larger number tried, up to 128. With 4 units it is 0.159, with 16 it is 0.059, and with 64 it is 0.004. The smooth target needs only 7 units. Any continuous target can be reached, but the number of units grows with how much the curve wiggles. Try drawing your own target too.

  3. In Depth, set 4 layers, so both networks have 8 units. Which fits the sawtooth better?

    Set the number of layers to 4, then try 6.

    The deep network matches the sawtooth exactly. Each layer folds the interval onto itself, doubling the number of teeth, so 4 layers make 16 straight pieces. A shallow network with 8 units has at most 9 pieces, one more than its number of kinks. Its error is 0.29 with evenly spaced kinks, and 0.25 with the best of 2,000 random placements of the kinks that we tried. To match the sawtooth exactly, one hidden layer needs 15 units; at 6 layers the deep network uses 12 units and the shallow one would need 63.

What the theorem does not say

The theorem is an existence result. It does not say how many units are needed; for general targets the number can grow exponentially with the dimension of the input. It does not say whether gradient descent will find the right parameters, or whether a network that fits finite data will generalize to new inputs (Section 2.8). Its lesson is that the ability to represent a function is rarely what limits a network.

Theorem Depth can make the number of units needed much smaller. Telgarsky built the sawtooth of the tool and proved that networks with few layers need exponentially many more units to approximate it.Telgarsky (2016), “Benefits of depth in neural networks,” COLT. Eldan and Shamir (2016), “The power of depth for feedforward neural networks,” COLT. Eldan and Shamir found a function of many inputs that a network with two hidden layers computes with a number of units growing only polynomially in the input dimension, while a network with one hidden layer needs a number growing exponentially.

The smooth target (ink) and fits with 4, 8, and 32 units (blue), with each unit’s contribution, a ReLU ramp, drawn faintly beneath. With 32 units the fit cannot be told apart from the target at this size.

Check

A one-hidden-layer ReLU network with 20 units has one input. At most how many straight pieces can its output have?

Each unit bends the output at one point, its kink, so 20 units give at most 20 bends and 21 pieces. A deeper network with 20 units can have many more.

A network with a million hidden units is trained on a dataset and still fits it badly. Does this contradict the universal approximation theorem?

The theorem guarantees that a good setting of the parameters exists. It says nothing about whether gradient descent reaches it, how long that takes, or how well the result generalizes.

Takeaway

A network with one hidden layer and a non-polynomial activation function can approximate any continuous function on a bounded region, given enough units; with ReLU, the units are bends that build any curve from straight pieces. The theorem guarantees existence only, not efficient size, success of training, or generalization, and depth can make the needed size exponentially smaller.
