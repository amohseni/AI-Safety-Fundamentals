Why nonlinearity matters

A layer of neurons (Section 2.2) multiplies its input vector by a matrix \(W\), adds a bias vector \(b\), and applies the activation function \(f\) to each entry: \(h = f(Wx + b)\). A network stacks such layers, each reading the previous layer’s output.

The activation function is the only part of a layer that is not linear. This page asks what it contributes: what a stack of layers can do with it, and what the same stack can do without it. The most common activation function is ReLU, \(\max(0, z)\), which leaves a positive number alone and sets a negative one to zero. GELU is a smooth version of it, and tanh and the sigmoid are S-shaped curves.

Three activation functions, and softmax. ReLU is zero for negative inputs and the identity for positive ones; GELU is a smooth curve close to it; the sigmoid rises from 0 to 1. Softmax, used in transformers, turns the scores 2, 1, 0 into the probabilities 0.67, 0.24, 0.09.

More pieces let the boundary bend in more places.

Why the layers collapse

Theorem Without activation functions, two layers compute \(W_2(W_1x + b_1) + b_2 = (W_2W_1)\,x + (W_2b_1 + b_2)\), which is one layer with matrix \(W_2W_1\). (Strictly, a map \(x \mapsto Wx + b\) is affine: a linear map plus a constant. Machine learning calls such a layer linear, and so does this site.) By the same step, any stack of linear layers collapses into a single linear layer, however many layers it has, and a single linear layer followed by one output neuron can separate classes only with one hyperplane. The activation functions are what give depth its power. A network whose activation functions are all ReLU computes a piecewise linear function: linear on each piece, with the pieces fitting together into a bent surface.

The nonlinear parts of current language models are few and simple. GPT-2 uses GELU in its feed-forward layers, and many recent models, such as Llama, use a gated variant called SwiGLU.Hendrycks and Gimpel (2016), “Gaussian error linear units (GELUs),” arXiv:1606.08415; Shazeer (2020), “GLU variants improve transformer,” arXiv:2002.05202; Touvron et al. (2023), “LLaMA: open and efficient foundation language models,” arXiv:2302.13971. Transformers have a few other nonlinear operations: softmax, which turns a list of scores into probabilities (in attention and at the output); normalization layers (LayerNorm or RMSNorm), which rescale each vector to a standard size; and the step in attention that multiplies two quantities that both depend on the input (Section 3.4).Ba, Kiros, and Hinton (2016), “Layer normalization,” arXiv:1607.06450; Zhang and Sennrich (2019), “Root mean square layer normalization,” Advances in Neural Information Processing Systems 32. Everything else is matrix multiplication and addition. This matters for interpretability (Section 6): much of the computation is linear, and linear computation is comparatively easy to analyze.

Check

A network has 50 layers, each of width 1,000, and no activation functions. Which functions of its input can it compute?

Each layer is linear, and a composition of linear maps is a linear map, so the 50 layers multiply out to one matrix and one bias vector. Depth adds nothing without activation functions.

In the playground, a network with ReLU in layer 1 and no activation function in layers 2 and 3 classified the spirals well. Which network computes the same family of functions?

Layers 2 and 3 and the output neuron multiply out to one linear map, so what remains is one ReLU layer followed by one linear output: a network with one hidden layer.

Takeaway

Stacked linear layers collapse into one linear map, so without activation functions a deep network is no more expressive than a single layer. The activation functions give depth its power: a ReLU network is piecewise linear, and its pieces let the boundary bend. A transformer is mostly matrix multiplication, with a few simple nonlinear operations in between.
