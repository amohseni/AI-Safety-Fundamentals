Circuits and activation patching

A circuit is a set of model components, such as particular attention heads and MLP neurons, together with the connections between them, that carries out a specific behavior. Finding one is the most detailed form of mechanistic interpretability (Section 6.1).

The main tool is activation patching. Run the model on a clean input and on a corrupted input that differs from it in one relevant way. For example, the clean input “When Mary and John went to the store, John gave a drink to” should be completed with “Mary”; the corrupted input “When Mary and John went to the store, Mary gave a drink to” should be completed with “John”. The logit difference is the model’s score (logit) for the clean answer minus its score for the corrupted answer. Now run the corrupted input again, but copy in one component’s activation from the clean run. If the logit difference moves back toward its clean value, the component carries information that decides the answer.

Empirical finding Wang et al. used patching to map a circuit of 26 attention heads in GPT-2 small, grouped into 7 classes, that performs this task.Wang, Variengien, Conmy, Shlegeris, and Steinhardt (2022), “Interpretability in the Wild: a Circuit for Indirect Object Identification in GPT-2 small,” arXiv:2211.00593. The task is called indirect object identification. In outline: earlier heads detect that “John” appears twice; heads called S-inhibition heads use that to stop the later heads from attending to “John”; and the later heads, called name movers, attend to the other name, “Mary”, and copy it to the output. The circuit also contains backup name movers, which take over when the main name movers are removed, and negative name movers, which push the other way.

Patching GPT-2 needs the model itself, which this site does not run. The tool on this page runs a smaller model in your browser: the modular-addition transformer of Section 5.4, which computes \((a + b) \bmod 59\). It reads the three tokens “a b =” and gives its answer at the “=” position. It has one attention layer with four heads, then an MLP with 512 neurons. This is the trained model of the main run in Section 5.4, with its real parameters.

For this model the clean input is a pair such as 12 + 30, with answer 42, and the corrupted input changes one number, as in 20 + 30, with answer 50. The logit difference is the logit for 42 minus the logit for 50. Patching a component gives a new logit difference, and the share of the gap it closes is

$$\text{restored} = \frac{\text{patched} - \text{corrupted}}{\text{clean} - \text{corrupted}},$$

where each term is a logit difference. Restored is 0% if the patch changes nothing and 100% if the patched run scores the two answers as the clean run does. It can fall below 0% or rise above 100% when the patch overshoots in either direction.

Empirical finding Nanda et al. reverse-engineered this kind of model completely.Nanda, Chan, Lieberum, Smith, and Steinhardt (2023), “Progress measures for grokking via mechanistic interpretability,” ICLR 2023. They used \(p = 113\), and their model used five key frequencies; this site uses \(p = 59\) so the model trains on a CPU (Section 5.4), and the model trained here uses three. The embedding maps each number \(a\) to the cosine and sine of \(wa\) for a few frequencies \(w = 2\pi k / p\). The attention and MLP layers combine \(a\) and \(b\) using the identity \(\cos(w(a + b)) = \cos(wa)\cos(wb) - \sin(wa)\sin(wb)\), and the same for the sine. The output layer gives each candidate answer \(c\) a score that is largest when \(\cos(w(a + b - c))\) is largest, which happens when \(c = (a + b) \bmod p\). The frequencies are the key frequencies of Section 5.5. Patching lets you check which components carry the information.

Activation patching

Choose a clean pair and the corrupted input, then patch one component at a time from the clean run into the corrupted run. Neurons 1 are the MLP neurons whose activation, over all pairs, varies mainly at frequency 1, and likewise for 12 and 27 (every neuron falls in one of these three groups). Each patch adds a bar showing how much of the logit difference it restored.

The full patching map for the clean pair: one row per component, one column per corrupted value. The frequencies in the embedding

Bars: the size of each frequency \(k\) in the model’s number embeddings (as in Section 5.5). Circle: each number’s embedding, keeping only its part at the selected frequency, on the same scale for every \(k\). Removing a frequency replaces the embeddings by their constant part and their parts at the other frequencies; the test accuracy is then computed on all test pairs.

  1. Clean 12 + 30, corrupted 20 + 30. Patch each of the four heads, then the MLP output. Which restores the most of the logit difference?

    Patch them one at a time. Then patch all four heads at once.

    The MLP output restores 95%. Of the heads, head 2 restores 61% and head 1 24%; heads 0 and 3 restore almost nothing for this pair. Patching all four heads restores exactly 100%, for every pair of inputs. That 100% is guaranteed by the model’s design, so it is no evidence about the heads: the “=” position starts from the same vector for every input, the heads are the only route by which \(a\) and \(b\) reach it, and copying all four head outputs therefore copies everything the rest of the model sees. The MLP output falls short of 100% because the head outputs also reach the logits directly, by the residual stream, and those stay corrupted. The MLP output carries almost all of what decides the answer, and the MLP computes it from what the heads bring.

  2. Keep 12 + 30 as the clean pair and change the corrupted value of \(a\) from 20 to other numbers. Will patching head 2 keep restoring about 61%?

    Move the corrupted value and patch head 2 again. After you have patched three different components, open the full patching map.

    It changes a lot: for this clean pair, head 2 restores between 13% and 107%, depending on the corrupted value. Empirical finding Over all 3,481 clean pairs and all 58 corrupted values of \(a\), one head alone restores 18% to 31% on average (head 0 least, head 3 most), and which head restores the most varies: head 3 in 34% of cases, head 2 in 28%, head 1 in 22%, head 0 in 16%. The MLP output restores between 86% and 105% in every case. A patching result answers a question about one clean input and one corrupted input.

  3. Back at clean 12 + 30 and corrupted 20 + 30, patch only Neurons 12, the 149 neurons that vary mainly at frequency 12. How much of the logit difference do they restore?

    Patch Neurons 12, then Neurons 1 and Neurons 27, and compare their sum with the MLP output.

    Neurons 12 restore 49%, Neurons 27 restore 39%, and Neurons 1 restore 8%. The three add up to the MLP output’s 95% exactly, because each neuron’s effect on the logits is added to the others’. Empirical finding Over all clean pairs and corrupted values, each group restores 28% to 34% on average. Each frequency carries part of the evidence for the answer, and no one group carries all of it.

  4. In the frequency panel, find the key frequencies, the few that stand out. Remove one of them and keep the other two. What happens to test accuracy?

    Select frequencies with the slider or by tapping the bars, and look at the circle for each. Use Keep only the three largest, then put back all and remove one key frequency.

    The key frequencies are 1, 12, and 27, and only at those three do the numbers form a circle. Keeping only these three leaves test accuracy at 100%, and removing any one of the other 26 also leaves 100%. Removing one key frequency drops accuracy to 31% to 37%, and removing all three drops it to 1.8%, about the rate of guessing one answer in 59. Each key frequency is needed; the others are not.

How the model adds 12 and 30. Left: at frequency 12, \(\cos(wa)\) and \(\sin(wa)\), with \(w = 2\pi \cdot 12/59\), place each number \(a\) on a circle at angle \(wa\), so the angle of 12 plus the angle of 30 is the angle of 42; the identity above is what computes the cosine and sine of that sum. Middle: the score \(\cos(w(42 - c))\) for each candidate \(c\), at the three key frequencies 1, 12, and 27. Each peaks at \(c = 42\), and the three disagree elsewhere, so their sum (ink) has one clear peak. Right: the trained model’s actual logits for 12 + 30, highest at 42. A constant plus the three cosines, weighted 14.3, 16.0, and 16.4, accounts for 98.9% of their variance over \(c\).

What the patching shows

Empirical finding In this model the pieces of the circuit can be named. Each head carries information about \(a\) and \(b\) mostly at one frequency. Of the variation in what head 0 would write from the position of \(a\) (its value for \(a\), passed through its output matrix), 90% is at frequency 1; for head 1, 79% is at frequency 27; for head 2, 71% is at frequency 12; head 3 is mixed (46% at frequency 12, 32% at 27, 22% at 1). That is why, for 12 + 30 against 20 + 30, head 2 and the frequency-12 neurons restore the most. The MLP neurons each respond mainly to one key frequency (444 of the 512 have more than 85% of their variance at it) and combine \(a\) and \(b\), and the output layer adds up their votes for each candidate answer. Section 5.4 showed this model grokking; this is the algorithm it grokked.

The patching on this page copies an activation from the clean run into the corrupted run, which tests whether that activation is enough to bring back the clean answer. The reverse, copying from the corrupted run into the clean run, tests whether the activation is needed to keep the clean answer, and the two tests can disagree.Heimersheim and Nanda (2024), “How to use and interpret activation patching,” arXiv:2404.15255, call the first direction denoising and the second noising, and discuss how results depend on the choice of inputs and measure. Ablation, which removes a component for every input, also tests what is needed; the frequency panel is an ablation of the embedding. Empirical finding Ablating one head, by replacing its output with its average over all pairs, lowers test accuracy to between 49% and 69%, depending on the head, so each head is needed.

A patching result depends on the choices made: which component, which clean and corrupted inputs, which direction, and which measure. A large restored share shows that a component carries much of the information that decides the answer for those inputs. It does not show that the component computes the answer by itself: the MLP output restores 95% here, and the MLP still depends entirely on the heads.

Circuit analysis of large models is slow and incomplete. Attribution graphs automate part of it: they trace the computation through a simplified replacement model, in which the MLP neurons are replaced by more interpretable features (Section 6.5). Empirical finding With them, Lindsey et al. found that Claude 3.5 Haiku, asked to complete a rhyming couplet, often activates features for candidate rhyme words at the line break after the first line, before it writes any of the second line, and that changing those features changes the word the second line ends with.Lindsey et al. (2025), “On the Biology of a Large Language Model,” Transformer Circuits Thread, section “Planning in Poems”. They found such planned-word features in about half of the poems they examined.

Check

For clean 12 + 30 and corrupted 20 + 30, patching head 3 from the clean run into the corrupted run restores about 0% of the logit difference. What does that show?

Copying from clean to corrupted tests whether an activation is enough to restore the clean answer, for the inputs chosen. Whether head 3 is needed is a different test: replacing head 3’s output with its average over all pairs lowers test accuracy to 49%, more than ablating any other head.

For one clean input and one corrupted input, patching head 3 restores 80% of the logit difference. What should you do before calling head 3 the head that matters?

One pair of inputs can make any head look important. In this model, which head restores the most changes from one pair of inputs to the next, and every head restores 80% or more for some pairs. The numbers are reliable; they answer a question about the inputs chosen.

Takeaway

A circuit is a set of components and connections that carries out a behavior. Activation patching is its causal test: copy one component’s activation from a clean run into a corrupted run and measure how much of the clean behavior returns. A large effect shows that the component carries information that decides the answer for those inputs, and so is enough to restore it; whether the component is needed, and whether it computes the answer alone, take further tests. In the modular-addition transformer the whole circuit is known: the heads carry \(a\) and \(b\) at a few key frequencies, the MLP combines them, and the output picks the \(c\) where the cosines of \(w(a + b - c)\) agree.
