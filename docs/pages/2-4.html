Layers bend space

The four clusters of the XOR dataset sit at the corners of a square, with each class on one diagonal. No single line separates the blue points from the orange ones. A network with two small hidden layers usually learns to classify them. This page shows how: each hidden layer moves the points, and after the last hidden layer one line can separate them.

Each layer does two things. First a linear map, plus a shift, rotates, stretches, shears, or flattens space. Then the activation function bends it. The network on this page uses the hyperbolic tangent, tanh, which squashes each coordinate into the range from \(-1\) to \(1\). ReLU, the other common choice, sets every negative coordinate to zero. For a network with two hidden layers,

$$h_1 = \tanh(W_1 x + b_1), \quad h_2 = \tanh(W_2 h_1 + b_2), \quad \text{output} = \sigma(w \cdot h_2 + b).$$

The output is a single neuron (Section 2.2). It draws one line through the space of \(h_2\) and reports which side of that line each point is on. The width of the network is the number of units in each hidden layer. At width 2 the hidden spaces are planes; at width 3 they are three-dimensional, and the output draws a plane instead of a line.This way of picturing a network comes from Chris Olah (2014), “Neural Networks, Manifolds, and Topology.”

Watch the plane bend

Train a network, then move the slider to follow the points and a grid drawn over the input plane through each step. The arrow keys move the slider one step at a time. At width 3, drag the picture, or select it and use the arrow keys, to turn it.

  1. XOR, width 2. After training, at which step do the two classes first become separable by a single line?

    Choose XOR and width 2, train until the accuracy reaches 100%, then move the slider one step at a time.

    In every successful run we tested, the classes first become separable after layer 1’s activation. Layer 1’s linear map cannot separate them: if a line separated the points just after a linear map, that line, mapped back, would already separate them in the input, and no line does. The bending done by the activation is what makes them separable.

  2. Spirals, width 2. If you train for the full 6,000 steps, will the network classify every training point correctly?

    Train spirals at width 2 until training stops. Then switch to width 3 and train again; press New start to try other starting points.

    Empirical finding At width 2, training stalls well short of 100%: in our runs, between 65% and 84%. At width 3 the network can lift one spiral above the other, and accuracy goes higher: the first two starting points reach 100%, and the others end between 85% and 99%. The extra dimension gives the layers room to separate what they could not separate in the plane.

  3. After training on spirals, look at the input step, where the shading shows which class the network assigns to each region. Is the boundary between the shaded regions curved or straight?

    Compare the input step with the last step, where the network’s own boundary is drawn.

    In the input the boundary curves around the spirals. At the last step the boundary is one line, or one plane at width 3. The curvature in the input comes from the hidden layers, which moved the points; the output only draws a straight boundary in the space they produce.

A trained XOR network at width 2, step by step. In this run the first linear map squeezes the plane almost onto one line, along a diagonal. The activation then bends that line into an L, with one class at the corner and the other on the arms, so a line can now separate them. After layer 2, the output’s line does.

Check

A trained network’s boundary in the input plane is curved. Where does the curvature come from?

The output is one neuron, so its boundary is flat in the space it sees. That space is the input after the hidden layers have bent it, so the same boundary looks curved in the input.

Takeaway

A multilayer network is a sequence of geometric transformations: linear maps that rotate, stretch, and flatten, and activation functions that bend. The hidden layers move the data until a single hyperplane separates the classes, and the output draws that hyperplane.
