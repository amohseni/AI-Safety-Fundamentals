Radical interpretation

David Lewis posed the problem of radical interpretation about an imagined person, Karl: given all the physical facts about Karl, solve for his beliefs, his desires, and what his words mean.Lewis (1974), “Radical interpretation,” Synthese 27: 331–344. Davidson (1973), “Radical interpretation,” Dialectica 27: 313–328, draws the evidence more narrowly: the speaker’s behavior only, in particular which sentences the speaker holds true in which observable circumstances. Herrmann and Levinstein put an AI system in Karl’s place.Herrmann and Levinstein (2026), Radical AI Interpretability, arXiv:2606.26523. Section numbers on this page refer to that version. The evidence then comes in two kinds: facts about the system’s internals, such as its parameters and architecture, and facts about its behavior (§1.1).

The interpreter is looking for an agential description with three parts: a belief function \(P\), which gives the system’s subjective probabilities; a desire function \(D\), which says how much the system wants each proposition to be true; and an algebra of propositions on which both are defined. A description is correct only if the system’s behavior can be rationalized as maximizing expected desire, with the expectation taken under \(P\) (§1.2). Candidate descriptions are tested by how well they predict behavior and by how rational the agent then appears (§1.3).

Two views say what makes an attribution correct. On interpretationism, a system has certain beliefs and desires if and only if attributing them gives the best theory of the system: the most accurate, powerful, and tractable one (§2.2, §3.1). On representationalism, it has them if it contains internal representations that play the right functional roles. The book sees no reason to choose between the two views or to treat them as competitors (§3.1).

The book uses the decision theory of Jeffrey and Bolker, in which actions, states of the world, and outcomes are all propositions in one algebra (§3.4.2).Jeffrey (1965), The Logic of Decision, McGraw-Hill. Bolker (1967), “A simultaneous axiomatization of utility and subjective probability,” Philosophy of Science 34: 333–340. The desirability of a proposition is the average desirability of the ways it can be true, weighted by the agent’s credences: for any way of dividing \(A\) into cases \(S_1, \dots, S_n\), \(D(A) = \sum_i D(A \wedge S_i)\, P(S_i \mid A)\) (§3.4.3). The agent takes the action whose desirability is highest. The question for this page is whether the agent’s behavior is enough to fix \(P\) and \(D\).

One behavior, many minds

Each task below asks for a prediction first. Make it, then use the tool to check it.

The agent

A coding agent must choose which file to edit. The bug is in the parser, in the renderer, or elsewhere. Set the agent’s credences in the three locations and its desirabilities for each action and location. The table shows the desirability of each action, computed by averaging, and the action the agent takes.

Another belief-desire pair

Choose constants \(a\), \(b\), \(c\). The tool sets \(d\) so that the new credences add up to 1, and builds a new pair \(P'\), \(D'\) by applying \(P'(A) = P(A)\,(cD(A) + d)\) and \(D'(A) = (aD(A) + b)/(cD(A) + d)\) to every proposition. The probe switch compares \(P'\) with what a truth probe reads from the system; in this toy the probe is assumed to read the agent’s credences exactly.

  1. In The agent, set the credence that the bug is in the parser to 1. What is the desirability of editing the parser now?

    Move the parser credence to 1.00 and read the first row of the table. Then move it back down and watch the action values change.

    With credence 1 in one location, the average has only one term, so the desirability of editing the parser equals the desirability of editing the parser when the bug is there: 1.00 at the starting values, and the agent now edits the parser. At intermediate credences each action’s desirability is a credence-weighted average of its row.

  2. Press Reset. In Another belief-desire pair, set \(c\) to 0.5, leaving \(a = 1\) and \(b = 0\). Will the new pair choose a different action?

    Set \(c\) and compare the two tables. Then try other values of \(a\), \(b\), and \(c\), and change the agent’s credences and desirabilities in the first panel.

    The choice does not change, and neither does the ranking of the three actions, although both the credences and the desirabilities do. Under the new pair the credence in each location even depends on the action: at the starting values with \(c = 0.5\), the new credence that the bug is in the parser is 0.45 given that the agent edits the parser and 0.21 given that it edits the renderer. In every allowed case we tested, the two pairs ordered all 511 propositions of this algebra the same way. Constants with \(ad - bc \le 0\) are refused: with \(a = -1\), for example, the ranking would reverse.

  3. Turn the probe reading on, so that \(P'\) must match what the probe reads. Which constants can you still change without contradicting the probe?

    With the probe on, move each of \(a\), \(b\), and \(c\) and read the verdict under the tables.

    Any \(c\) other than 0 changes the credences, so the probe rules it out. With \(c = 0\) the tool sets \(d = 1\), and the new desire function is \(D' = aD + b\): the same desirabilities on a new scale with a new zero point. Among these transformations, a reading of \(P\) from inside the system fixes the beliefs exactly and leaves only the scale and zero of \(D\) open.

Why behavior leaves the answer open

Theorem Bolker’s uniqueness theorem: let the propositions form an atomless algebra and let the preferences over them satisfy Bolker’s axioms. If two belief-desire pairs represent the same preferences, they are related by the transformation below, for constants with \(ad - bc > 0\) (§3.4.4 and its footnote 43). Conversely, applying the transformation to a representing pair, with \(cD(A) + d > 0\) for every proposition \(A\) and \(cD(T) + d = 1\) (explained below), gives another representing pair.

$$P'(A) = P(A)\,\big(cD(A) + d\big), \qquad D'(A) = \frac{aD(A) + b}{cD(A) + d}.$$

The book states the transformation for the measure \(v = DP\) and for \(P\): \(v' = av + bP\) and \(P' = cv + dP\); the form above follows by dividing. Because \(D'\) is an increasing function of \(D\) whenever \(ad - bc > 0\), the two pairs rank every proposition the same way, and because \(v'\) and \(P'\) add up over cases, \(D'\) is again the average of its cases under \(P'\). The new credences add up to \(cD(T) + d\), where \(T\) is the proposition that is always true. So \(P'\) is a probability only when \(cD(T) + d = 1\), which is how the tool sets \(d\); under the common convention \(D(T) = 0\), this means \(d = 1\). Rescaling \(P'\) to add up to 1 instead is the same as dividing all four constants by one positive number, which leaves \(D'\) unchanged. The theory assumes an atomless algebra (§3.4.2). The tool’s algebra has only nine atoms, and on so small an algebra still other pairs fit the same preferences; the tool shows only the transformations of the theorem.

Theorem If \(P' = P\) for every proposition, then \(cD(A) + d = 1\) wherever \(P(A) > 0\); as soon as \(D\) takes two different values, this forces \(c = 0\) and \(d = 1\), so \(D' = aD + b\) with \(a > 0\). The book also notes that \(P\) becomes unique, and \(D\) unique up to scale and zero, if desirability is unbounded above and below, or if the agent’s comparative probability judgments are known (§3.4.4).

Inverse reinforcement learning, which infers a reward from behavior, meets the same problem: many reward functions make the same behavior optimal, and a constant reward makes every behavior optimal.Ng and Russell (2000), “Algorithms for inverse reinforcement learning,” Proceedings of the 17th International Conference on Machine Learning. Argument Herrmann and Levinstein argue that internal evidence can break the tie that behavior leaves: a probe that tracks truth would narrow the belief functions that are admissible (§3.4.4). Lewis’s formulation already counts the internal facts as evidence; with AI systems, interpretability methods (Section 6) let the interpreter actually gather them.

Three aspects of a system, following the description of Herrmann and Levinstein’s Figure 1 (§1.5). The computational system produces behavior; the agential description (a belief function, a desire function, and an algebra of propositions) describes that behavior as maximizing expected desire; mechanistic interpretability links the internal structure to the description. Radical interpretation is the project of getting all three to cohere.

Check

Two interpreters watch the same coding agent in every situation it could face. One attributes the pair \((P, D)\); the other attributes the pair obtained from it with \(a = 1\), \(b = 0\), \(c = 0.5\), and \(d\) set so that the credences add up to 1. Which attribution does the behavioral evidence favor?

The two pairs are related by Bolker’s transformation, so they rank every proposition, and so every action, the same way. No observation of the agent’s choices can tell them apart.

In the Jeffrey-Bolker theory, suppose a probe has been shown to read an agent’s credences exactly. What can two attributions that fit both the behavior and the probe still disagree about?

Fixing \(P\) forces \(c = 0\) and \(d = 1\), which leaves \(D' = aD + b\) with \(a > 0\). The order of the desirabilities is fixed; their unit and zero are not.

Takeaway

To interpret a system is to find a belief function, a desire function, and an algebra of propositions under which its behavior maximizes expected desire. In the Jeffrey-Bolker theory many such pairs fit the same preferences, so behavior alone cannot settle the attribution. Evidence from inside the system, such as a probe that reads the credences, narrows the family: fixing the credences leaves the desire function open only up to its scale and zero point.
