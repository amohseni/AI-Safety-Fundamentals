Loss as a proper scoring rule

A language model outputs a probability for every possible next token. Training scores that output with the cross-entropy loss: minus the natural log of the probability the model gave to the token that actually came next. If the model gave the right token probability 0.9, the loss is 0.105. If it gave the right token probability 0.01, the loss is 4.6.

The same kind of score is used to grade weather forecasters. A scoring rule takes a forecast and the outcome and returns a loss. This page compares three rules for a yes-or-no event, where you report a probability \(q\) that the event happens:

  • the log rule charges minus the log of the probability you gave to what happened;
  • the Brier rule charges the squared distance between your report and the outcome, counted as 1 if the event happened and 0 if not;
  • the linear rule charges one minus the probability you gave to what happened.

The question is which rule rewards a forecaster for reporting what they actually believe.

  1. Under the linear rule, with \(p = 0.7\), which report gives the lowest expected loss?

    Now check it: in One forecast, choose Linear, set \(p\) to 0.70, and move \(q\).

    The lowest point is at \(q = 1\). Reporting certainty you do not have lowers your expected loss from 0.42 to 0.30. The linear rule rewards overconfidence.

  2. Switch to the log rule, still with \(p = 0.7\). Which report is best now?

    Check it, then move \(p\) and watch where the lowest point goes. Try the Brier rule too.

    Under the log rule the lowest point is always at \(q = p\): the only way to do best is to report what you believe. The Brier rule behaves the same way. As \(q\) approaches 0 or 1, the log loss rises without limit.

  3. With the log rule and \(p = 0.7\), run 1,000 events. Which forecaster ends with the lowest average loss?

    Run it in Many forecasts. Then switch the rule to Linear and run again.

    Under the log rule the honest forecaster has the lowest average loss; under the linear rule the overconfident one does. Over many events, the average loss settles at the expected loss, so whatever a rule rewards in expectation is what training under that rule ends up rewarding.

  4. In the next-token panel, drag the bar for “also” down to zero. What happens to the expected loss?

    Try it.

    The loss becomes infinite. The token “also” comes next 7% of the time, and each time it does, a model that gave it probability zero pays \(-\log 0\). A model trained this way learns never to give probability zero to a token that occurs in its training text.

Why honest reports win

A scoring rule is strictly proper if a forecaster minimizes their expected loss only by reporting their true probabilities.Gneiting and Raftery (2007), “Strictly proper scoring rules, prediction, and estimation,” Journal of the American Statistical Association 102: 359–378. Theorem The log rule and the Brier rule are strictly proper; the linear rule is not. For the log rule, when the event has probability \(p\) and you report \(q\), your expected loss (natural log) is

$$\mathbb{E}[L(q)] = -\,p \log q \;-\; (1-p)\log(1-q).$$

Its derivative is zero only at \(q = p\), where the curve has its minimum. The linear rule’s expected loss is a straight line in \(q\), so its minimum is always at an end: at \(q = 1\) whenever the event is more likely than not.

Expected loss against the reported probability \(q\), when the event happens with probability 0.7, on a shared scale. The log and Brier rules are lowest at \(q = 0.7\); the linear rule is lowest at \(q = 1\).

What this means for language models

Argument Because the training loss is strictly proper, training to predict the next token pushes a model toward calibrated probabilities: among the cases where it says 70%, the event should happen about 70% of the time. Empirical finding The GPT-4 technical report found the pretrained model well calibrated on a multiple-choice benchmark, and less calibrated after further training with human feedback.OpenAI (2023), “GPT-4 Technical Report,” the calibration figure for the MMLU benchmark. Section 4 of this site explains the later training.

A common belief is that language models learn by reinforcement learning. Pretraining is not reinforcement learning. Its targets come from the text itself, so it is supervised learning, often called self-supervised learning. Reinforcement learning enters only in later training, where the model’s own outputs are scored (Section 4.1).

Check

Suppose a model were trained with the linear rule instead of the log rule. Would you expect the probabilities it reports to be calibrated?

The linear rule is not proper: its expected loss is lowest at an end, so a model trained with it gains by reporting 0 or 1. Calibration comes from the rule being strictly proper.

What kind of learning is pretraining?

Each next token in the training text is the target, and the model is scored on it with the log rule. No reward signal is involved.

Takeaway

Cross-entropy is the logarithmic scoring rule. It is strictly proper, so the best a model can do is report the probabilities the data supports, and next-token training pushes models toward calibration. Pretraining is supervised learning; reinforcement learning comes later.
