Learning means choosing parameters

A neural network is a function. It takes an input, such as the pixel values of an image or a sequence of words, and returns an output, such as a label or a probability for each possible next word. The function has adjustable numbers called parameters. We write the function as \(f(x; \theta)\), where \(x\) is the input and \(\theta\) is the list of all the parameters. Different parameter values give different functions from the same family.

A network as a box. The input \(x\) goes in and the output \(y\) comes out; the knobs on top are the parameters \(\theta\). Turning a knob changes which function the box computes.

Learning means choosing parameter values so that the function’s outputs match a set of examples \((x_1, y_1), \dots, (x_n, y_n)\). To make “match” precise we need a loss: a number that measures how badly the function does on the examples. On this page the loss is the mean squared error,

$$L(\theta) = \frac{1}{n}\sum_{i=1}^{n} \big(f(x_i; \theta) - y_i\big)^2 .$$

Training searches for parameter values with a low loss. Section 2.5 explains which loss to use for probabilities, and Section 2.6 how the search is done automatically. A function with two or three parameters can be fitted by hand, by turning the knobs yourself. GPT-3 has 175 billion parameters.Brown et al. (2020), “Language models are few-shot learners,” Advances in Neural Information Processing Systems 33. The rest of this section explains how a search over that many numbers is possible.

Fit by hand

Choose a model and move its sliders. The left chart shows the 20 points and the model’s curve; the gray segments are the errors. The right chart is a map of the loss over two parameters: the shading is heaviest where the loss is lowest, and the dot is your current setting. Press or drag on the map to move the dot. Each model has its own 20 points, made from one member of its family plus random noise.

  1. With the line, what is the lowest loss you can reach?

    Move the slope and intercept, or drag on the map, until the loss stops going down.

    About 0.32, at slope 0.91 and intercept 0.32. No line goes through all 20 points, because the points contain noise, so the loss cannot reach 0. On the map the loss has one low point, at the bottom of a bowl.

  2. Switch to the wave. Its points were made from \(a = 1.5\), \(b = 1.5\), \(c = 0.5\), plus noise. Is that setting the one with the lowest loss?

    Set the three sliders to 1.5, 1.5, and 0.5 and read the loss. Then try to beat it.

    The setting that made the points has loss 0.120. Near \(a = 1.66\), \(b = 1.47\), \(c = 0.35\) the loss is 0.078. The lowest loss belongs to the setting that best fits these 20 noisy points, which is close to the true setting but not equal to it.

  3. With the wave and \(c = 0.5\), does the map have a low point, lower than everything around it, other than the best one?

    Look for shaded patches away from the most heavily shaded one, and drag the dot into them.

    Yes, several. For example, near \(a = -0.55\), \(b = 0.70\) the loss is 1.32, lower than at any nearby setting, while the best setting has loss 0.10. A search that only ever moves downhill and starts near such a point stops there. Section 2.6 returns to this.

Check

Two copies of the same network, with the same architecture, are trained on different data. In the terms of this page, what differs between the two trained models?

The architecture fixes the family of functions \(f(x; \theta)\). Training picks one member of the family by choosing \(\theta\), so a trained model is one function, picked out by one setting of the parameters.

Takeaway

A neural network is a function \(f(x; \theta)\) with adjustable parameters \(\theta\). Learning means choosing \(\theta\) so that the function fits a set of examples, which means searching for low points of the loss. The loss can have low points that are not the lowest.
