Backpropagation

Gradient descent needs the derivative of the loss with respect to every parameter (Section 2.6). A network is a composition of simple operations, so the chain rule gives each derivative as a product of local derivatives, one for each operation on the way from the parameter to the loss. For example, if \(z = w_1 x + b\), \(a = \sigma(z)\), and the loss \(L\) depends on \(a\), then the chain rule gives \(\partial L/\partial w_1\) as \(\partial L/\partial a\) times \(\partial a/\partial z = \sigma'(z)\) times \(\partial z/\partial w_1 = x\):

$$\frac{\partial L}{\partial w_1} = \frac{\partial L}{\partial a}\,\sigma'(z)\,x .$$

Backpropagation organizes this computation. First run the network forward and store every intermediate value. Then work backward from the loss, whose derivative with respect to itself is 1. Each operation receives the derivative of the loss with respect to its output, multiplies it by its own local derivative for each input, and passes the results to its inputs. Where a value feeds more than one operation, the derivatives coming back from those operations add. Each intermediate derivative is computed once and reused by everything upstream of it.

  1. With the default values, the forward pass gives \(p = 1.336\) while the target is \(y = 0.5\). Before pressing Backward: what is the sign of \(\partial L/\partial w_2\)?

    Press Forward until the loss is computed, then Backward until the derivative reaches \(w_2\).

    Positive: \(\partial L/\partial w_2 = 1.118\). The loss is \(d^2\) with \(d = p - y = 0.836\), so \(\partial L/\partial d = 2d\) is positive; \(\partial d/\partial p = 1\); and \(\partial p/\partial w_2 = a = 0.668\) is positive. The prediction is too high, and raising \(w_2\) would raise it further, so gradient descent will lower \(w_2\).

  2. Run the nudge test on \(w_1\). Will the change in loss per unit of nudge agree with the backpropagated derivative to the four decimals shown?

    Choose \(w_1\) and press Nudge test. Then move the sliders and run it again.

    Yes: both are 1.1126 at the default values. The nudge test needs two extra forward passes for each parameter it checks, while one backward pass gives every derivative at once. In 120,000 comparisons at random settings of the sliders, the two numbers never differed by more than 0.00003, and 99.9% agreed to all four decimals.

  3. Switch to the graph with a value used twice. At which node do two derivatives arrive and add?

    Press Backward one step at a time and read the explanation of each step.

    At \(h\). The value \(h = wx\) feeds both \(u = v_1 h\) and \(s = \sigma(h)\), so the loss depends on \(h\) along two paths. With the default values the two derivatives are \(-2.2370\) and \(0.3412\), and \(\partial L/\partial h\) is their sum, \(-1.8958\). Each backward step used only its own local derivative and the one number passed back to it.

Why backward

The loss is one number, and there are many parameters. Working backward, one pass delivers the derivative of that one number with respect to every node at once. Working forward instead, which is called forward-mode differentiation, one pass gives the derivative of every node with respect to one chosen input, so the full gradient would take one pass per parameter.

Theorem The backward pass costs at most a small constant multiple of the forward pass, whether the network has a thousand parameters or a trillion: in operation count the factor is below 6, and typically 2 to 3.Baydin, Pearlmutter, Radul, and Siskind (2018), “Automatic differentiation in machine learning: a survey,” Journal of Machine Learning Research 18, article 153, citing Griewank and Walther (2008). The price is memory, since every value from the forward pass is stored for the backward pass. This fact is what makes training large networks possible. The general technique is called reverse-mode automatic differentiation; libraries such as PyTorch and JAX apply it automatically to any computation written in them. Its use for training networks with hidden layers was popularized by Rumelhart, Hinton, and Williams in 1986 (Section 1.3).Rumelhart, Hinton, and Williams (1986), “Learning representations by back-propagating errors,” Nature 323: 533–536. For a visual account, see 3Blue1Brown, “Neural networks,” chapters 3 and 4 (2017); for a minimal implementation, Karpathy, “micrograd” (2020, on GitHub).

Check

A network has one loss and a million parameters. Forward-mode differentiation gives, in one pass, the derivatives of every node with respect to one chosen parameter. About how many passes does each method need for the full gradient?

Forward mode follows one parameter per pass, so it needs a million passes. Backpropagation starts from the single loss and reaches every parameter in one backward pass, after one forward pass.

In a graph, a value \(v\) feeds two operations. The derivatives they send back to \(v\) are 0.3 and \(-0.5\). What is \(\partial L/\partial v\)?

Where paths meet, the contributions add: \(0.3 + (-0.5) = -0.2\). This is the multivariable chain rule: the loss depends on \(v\) through both operations.

Takeaway

Backpropagation is the chain rule applied to the computation graph, from the loss back to the parameters. Each node multiplies the derivative passed back to it by its own local derivative, and contributions add where paths meet. One backward pass gives the derivative for every parameter at a small constant multiple of the cost of the forward pass.
