Optimizing a proxy

In 1975 the economist Charles Goodhart wrote that “any observed statistical regularity will tend to collapse once pressure is placed upon it for control purposes.”Goodhart (1975), “Problems of monetary management: the U.K. experience,” Papers in Monetary Economics, Reserve Bank of Australia. The anthropologist Marilyn Strathern later stated the idea in the form most people now quote: “When a measure becomes a target, it ceases to be a good measure.”Strathern (1997), “‘Improving ratings’: audit in the British University system,” European Review 5: 305–321, p. 308. The short form is hers; Goodhart’s own wording is the one quoted first. The idea is called Goodhart’s law.

In AI the measure is a reward function, a reward model (Section 4.2), a test suite, or a benchmark score. This site calls any measure optimized in place of the intended goal a proxy. This page uses the simplest model of one. Each option has a true value \(V\), and its proxy score is the true value plus an error, \(U = V + E\), where the error is independent of the true value. An optimizer that compares \(k\) options and keeps the one with the highest proxy score applies more pressure the larger \(k\) is.

Manheim and Garrabrant distinguish four ways Goodhart’s law can operate; two matter most here.Manheim and Garrabrant (2018), “Categorizing variants of Goodhart’s law,” arXiv:1803.04585. The other two are causal and adversarial Goodhart. In regressional Goodhart, selecting on the proxy also selects on its error: the options with the highest proxy scores are disproportionately those with large positive errors. In extremal Goodhart, the proxy and the goal are related one way over ordinary options and another way at the extremes a strong optimizer reaches.

Pushing past the data

The true value of a design \(x\) rises to a peak at \(x = 4\) and then falls. The proxy is a straight line fitted to 24 noisy measurements of designs between 0 and the end of the data. The optimizer picks the design with the highest proxy score within its search limit.

  1. Normal errors of size 1. As the selection strength grows from 1 to 1,000,000, what happens to the expected true value of the selected option?

    Check it: choose Normal, set the error size to 1, and move the selection strength from left to right.

    It keeps rising, and it stays at exactly half the expected proxy score: at \(k\) = 1,000,000 the expected proxy score is 6.88 and the expected true value is 3.44. Selection still pays, but half of the winner’s proxy score is error. A larger error size lowers that share: with errors of size 2, the true value at \(k\) = 1,000,000 is 2.17 and the proxy 10.87.

  2. Switch to Student’s t with 3 degrees of freedom, error size 1. These errors are heavy-tailed: very large errors are far more common than under the normal distribution. Near what selection strength does the expected true value stop rising?

    Check it, then try other degrees of freedom. Fewer degrees of freedom means heavier tails.

    The true value peaks at 0.88 near \(k\) = 22 and then falls. At \(k\) = 1,000,000 it is 0.03, close to 0, the true value of an average option, while the expected proxy score is 140. The winners are now almost all options with huge errors. With 10 degrees of freedom the peak comes later, near \(k\) = 900; with 30, the true value is still rising at \(k\) = 1,000,000 and peaks only near \(k\) = 20 million.

  3. Choose rare huge errors: one option in 1,000 has an error 30 times the usual size. With error size 1, compare selecting the best of 100 with selecting the best of 10,000.

    Check it, and look at the scatter: where does the winner come from?

    Best of 100 gives an expected true value of 1.70, close to the 1.77 that normal errors give. Best of 10,000 gives 0.09. Among 10,000 options about ten have a huge error, and one of them almost always has the top proxy score. A proxy can work well under moderate pressure and fail under strong pressure. Past about \(k\) = 17,000 the true value rises again, very slowly (0.11 at 1,000,000), because these errors are still normal in their far tail.

  4. In Pushing past the data, fit the proxy on designs from 0 to 3, and let the optimizer search up to 12. Compared with the best design between 0 and 3, is the design it picks better, about the same, or worse?

    Check it, then widen the data range and see whether a straight line can ever point the optimizer to the peak.

    Worse. Between 0 and 3 the fitted line tracks the true value closely and keeps rising, so the optimizer picks the largest design it may, 12, where the true value is −6. The best design between 0 and 3 has true value 1.9. Widening the data does not fix this: a line rises everywhere or falls everywhere, so the optimizer always picks an end of its range, never the peak at 4.

Why the tails decide

For normal errors of size \(s\), the expected true value of an option given its proxy score \(u\) is a straight line in \(u\):

$$\mathbb{E}[V \mid U = u] = \frac{u}{1 + s^2}.$$

So a higher proxy score always buys more true value, at a fixed rate. With error size 1 the rate is one half, which is why the true-value curve in task 1 stayed at half the proxy curve. With heavy-tailed errors the expected true value given the proxy score rises and then falls back toward zero as \(u\) grows: a very high proxy score is much more likely to come from a large error than from a large true value, because large errors are far more common than large true values.

Theorem Kwa, Thomas, and Garriga-Alonso prove the version of this with a threshold in place of best-of-\(k\).Kwa, Thomas, and Garriga-Alonso (2024), “Catastrophic Goodhart: regularizing RLHF with KL divergence does not mitigate heavy-tailed reward misspecification,” arXiv:2407.14503, Theorems 5 and 6. Let the error be independent of the true value. If the error is light-tailed, as normal errors are, and the true value has no upper bound, then the expected true value of the options whose proxy exceeds a threshold grows without limit as the threshold rises. If the error is heavy-tailed, with a tail much heavier than the true value’s, that expected true value tends to the average true value of all options: harder selection eventually buys nothing.

Their main result concerns reinforcement learning from human feedback, where the policy is trained to maximize the reward model’s score minus a penalty on its KL divergence from the base model (Section 4.3). With heavy-tailed reward-model error, some policies reach arbitrarily high reward at arbitrarily small KL divergence from the base model while gaining no true value over it. They call this catastrophic Goodhart. Empirical finding When they measured the tails of the scores given by open reward models, the tails were consistent with light-tailed error. The theorem is therefore a warning about reward sources that may have heavy-tailed error in the future.

Past the edge of the data

Argument The second panel shows extremal Goodhart. Inside the range of the data the fitted line is a good proxy. Outside it, nothing makes the line follow the true value, and an optimizer that searches beyond the data finds the designs where the two come apart. A reward model trained on ordinary outputs faces the same problem when reinforcement learning pushes the policy toward outputs unlike those it was trained on. Empirical finding Gao, Schulman, and Hilton measured this directly: as a policy was optimized harder against a learned reward model, its score under a separate “gold” reward model, which stood in for the true goal, first rose and then fell (Section 4.3).Gao, Schulman, and Hilton (2022), “Scaling laws for reward model overoptimization,” arXiv:2210.10760; published at ICML 2023.

Check

You pick the best of a million candidate answers using a reward model whose errors are heavy-tailed. What should you expect of the winner?

With heavy-tailed errors, the highest proxy scores come mostly from large errors. Independent errors do not push the true value below average; they make the winner’s true value close to that of a typical candidate.

A reward model was trained on answers of ordinary length. During reinforcement learning the policy finds that ever longer answers get ever higher reward, while their true quality drops. Which mechanism is this mainly?

The reward model’s link between length and quality held over ordinary answers. The optimizer pushed into lengths where that link was never checked, as the optimizer in the second panel pushed past the end of the data.

Takeaway

Optimizing a proxy selects for its errors and pushes toward options where the proxy was never checked. With light-tailed errors, harder optimization still improves the true value, by less than the proxy shows. With heavy-tailed errors, the highest proxy scores are mostly error, and harder optimization can stop improving the true value altogether.
