Double descent

Section 2.8 showed the classical U-shaped curve: as a model gets more parameters, test error first falls and then rises, as the model starts fitting the noise in its training data. The classical advice is to stop near the bottom of the U. But models can be made larger still, past the size at which they can fit every training example exactly, called the interpolation threshold. Past it, test error often falls again. This is double descent.Belkin, Hsu, Ma, and Mandal (2019), “Reconciling modern machine-learning practice and the classical bias-variance trade-off,” PNAS 116: 15849–15854. Nakkiran, Kaplun, Bansal, Yang, Barak, and Sutskever (2019), “Deep double descent: where bigger models and more data hurt,” arXiv:1912.02292; ICLR 2020.

The tool uses a model simple enough to fit exactly in the browser. There are 40 training points: the curve \(\sin(\pi x)\) plus random noise. The model is a weighted sum of \(p\) random features. Each feature is a ReLU unit whose parameters are drawn at random and then frozen, and only the parameters that multiply the features are fitted, by least squares. When there are more features than points, many settings of these parameters fit the points exactly, and the tool picks the one with the smallest sum of squared parameters, the minimum-norm solution.Each feature is \(\mathrm{ReLU}(w \cdot e(x) + b)\), where \(e(x) = (\cos 0.75\pi x, \sin 0.75\pi x)\) places \(x\) on an arc of a circle and \(w\) and \(b\) are random. With \(x\) alone, one-input ReLU features bend only between data points and many of them duplicate each other; the arc avoids that. Features with no bend among the 40 inputs are redrawn. Test error is the mean squared distance between the fitted curve and \(\sin(\pi x)\), at 200 new points.

Through the threshold

Each task below asks for a prediction first. Make it, then use the tool to check it.

  1. Set \(p = 40\), as many features as training points. What does the fitted curve look like?

    Press p = 40 and look at the fitted curve. Press New features a few times.

    The curve passes through or very near every noisy point and swings far from the true curve between them. With the default noise, over 20 feature draws the test error at \(p = 40\) was between 0.2 and 62, while the best model with fewer than 30 features scored about 0.03. The peak of the error curve is near \(p = 40\): in 16 of the 20 draws it fell between 36 and 44.

  2. Now set \(p = 400\), ten times more features than points. How does the test error compare with \(p = 40\)?

    Press p = 400; look at the fitted curve and the error chart.

    Much lower: between 0.08 and 0.10 in all 20 draws. The model still fits every training point exactly, but the curve between the points is far smoother. In this example the second descent does not go below the best small model (about 0.03); in some larger problems it does.

  3. Set the ridge strength to 0.001. What happens to the peak?

    Change the ridge strength and watch the error chart. Then set it back to 0 and lower the noise.

    It disappears. With ridge 0.001 the largest test error for any \(p\) of 20 or more was at most 0.040 over the 20 draws. With no noise, the peak also goes away: in the first draw the largest test error is then at \(p = 1\).

Why the peak sits at the threshold

Argument With fewer features than points, the model cannot pass through every point, so least squares averages over the noise. At the threshold the model has just enough features to pass through every point, and essentially one way to do it. That one fit must pass through the noise too, and to do that it uses large parameters, which make the curve swing between the points. With many more features than points, there are many exact fits, and the minimum-norm one spreads the work over many features with small parameters, which gives a smoother curve. Ridge regularization, which adds a penalty on the squared parameters, stops the fit from forcing its way through every noisy point at the threshold, and so removes the peak.

Theorem For a linear model trained by gradient descent on the squared error from all-zero parameters, the parameters converge to the minimum-norm solution, because every gradient step lies in the span of the training inputs. This is one reason large models trained from small parameters can find smooth fits. Empirical finding In deep networks double descent also appears as training time and dataset size grow, and it is strongest when the labels are noisy (Nakkiran et al.). It is one reason the classical advice to keep models small does not carry over to large networks.Schaeffer et al. (2023), “Double descent demystified: identifying, interpreting and ablating the sources of a deep learning puzzle,” arXiv:2303.14151, explains the peak in linear regression.

Check

The same random-feature model is fitted to 1,000 noisy training points. Near what number of features would you expect the test error to peak?

The peak sits at the interpolation threshold, where the number of features first matches the number of points the model must fit exactly: about 1,000.

Why does ridge regularization remove the peak?

The peak comes from a model forced through noisy points with large parameters. The penalty on the parameters lets the fit miss the points a little instead.

Takeaway

As a model grows, test error can fall, rise to a peak at the interpolation threshold, and fall again. At the threshold the model has essentially one exact fit, which must bend through the noise; far past it, the minimum-norm fit among many is smooth. Regularization or noise-free labels remove the peak.
