## 5.5 Grown, not programmed

**Aim.** The reader understands that nobody writes the algorithm a trained network uses: training selects parameters, and the resulting mechanisms must be discovered afterward, may differ between training runs, and may include mechanisms nobody intended.

**Text (draft).**

> Engineers write the training setup: the architecture, the data, the loss, and the optimizer. They do not write the algorithm the trained network ends up using. That algorithm is whatever the search found, encoded in millions or billions of numbers. Chris Olah's description is that these systems are grown more than they are built.
>
> Three consequences follow. First, there is no line of code to inspect for a given behavior; finding out how a network does something is an empirical research problem (Section 6). Second, training runs from different random starting points can reach the same accuracy with different internal mechanisms, although some features recur across runs and across models. Third, training selects any mechanism that achieves low loss or high reward, including mechanisms the designers did not intend and would not approve of (Section 8).

**Image.** Two panels. Left: a few lines of source code with one line highlighted as the cause of a behavior. Right: a weight matrix shown as a heat map, captioned "the same behavior, encoded in learned numbers".

**Interactive: "Five seeds".**

- Panel 1: the spirals network from Section 2, trained from 5 random starting points. Display: the five decision boundaries (nearly identical) and, for each run, the response of each hidden unit (very different).
- Panel 2: the modular-addition transformer trained from 5 starting points, all at 100% test accuracy. Display: which frequencies each run uses.
- Controls: pick runs to compare side by side; overlay boundaries.
- Try: (1) Compare the decision boundaries, then the hidden units. (2) Compare the frequencies the five modular-addition models use.
- What to notice: the same behavior can rest on different internals, and the internals have to be found by investigation.
- Build: precomputed; small.

**Check.** Where would you look to find the rule a trained network uses for a task? Answer: in its trained weights and activations, by investigation; the rule is written nowhere in its code.
