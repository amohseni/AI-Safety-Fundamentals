## 2.3 Why nonlinearity matters

**Aim.** The reader understands that stacked linear layers collapse into one linear map, so the activation functions are what give depth its power, and can name the few nonlinear operations in a current model.

**Text (draft).**

> A layer of neurons multiplies its input by a matrix W, adds a bias vector, and applies the activation function to each entry. Without the activation function, two layers compute W₂(W₁x + b₁) + b₂, which is the same as one layer with matrix W₂W₁. Any stack of linear layers collapses into a single linear layer, and a single linear layer can separate classes only with one hyperplane.
>
> The activation functions are the network's nonlinear parts, and they are simple. The most common is ReLU, which outputs max(0, z). Most current language models use smooth variants of ReLU, called GELU and SwiGLU, in their feed-forward layers. Transformers have two other nonlinear operations: softmax, which turns a list of scores into probabilities (in attention and at the output), and normalization layers (LayerNorm or RMSNorm), which rescale each vector to a standard size.
>
> So a transformer is mostly matrix multiplication, with a few simple nonlinear functions in between. This matters for interpretability (Section 6): much of the computation is linear, and linear computation is comparatively easy to analyze.
