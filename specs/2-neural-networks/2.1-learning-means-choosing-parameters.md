## 2.1 Learning means choosing parameters

**Aim.** The reader thinks of a neural network as a function f(x; θ) with adjustable parameters θ, and of learning as choosing θ so that f fits a set of examples.

**Text (draft).**

> A neural network is a function. It takes an input, such as the pixel values of an image or a sequence of words, and returns an output, such as a label or a probability for each possible next word. The function has adjustable numbers called parameters, or weights. Different parameter values give different functions.
>
> Learning means choosing parameter values so that the function's outputs match a set of examples. To make "match" precise we need a loss: a number that measures how badly the function does on the examples (Section 2.5). Training searches for parameter values with a low loss (Section 2.6).
>
> A function with two parameters can be fitted by hand, by turning two knobs. GPT-3 has 175 billion parameters. The rest of this section explains how a search over that many numbers is possible.

**Image.** A box labeled f(x; θ), with an input arrow x, an output arrow y, and a row of knobs on top labeled θ.

**Interactive: "Fit by hand".**

- Display: 20 noisy data points; the current model curve; vertical lines showing each point's error; the loss as a number; a heat map of the loss over two parameters, with the reader's current setting marked.
- Controls: model choice (a line y = ax + b, or a wave y = a sin(bx) + c); one slider per parameter.
- Try: (1) Get the loss below 1.0 with the line. (2) Switch to the wave and find the best fit. (3) In the heat map, find a second low point that is not the best one.
- What to notice: you are searching for low ground on the loss surface. Gradient descent (2.6) does this search automatically.
- Build: live; small.

**Check.** In this framing, what is "the model" after training? Answer: one function, picked out by one setting of the parameters.

**Links.** Forward to 2.5 (loss), 2.6 (gradient descent).
