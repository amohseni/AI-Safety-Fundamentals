## 3.6 The residual stream and the MLP

**Aim.** The reader adopts the residual-stream picture: each position carries one vector that every layer reads from and adds to. Attention moves information between positions; the MLP transforms it at each position and acts partly as a key-value memory.

**Text (draft).**

> Each position in a transformer carries a vector, called the residual stream; in GPT-2 small it has 768 numbers. The embedding writes its first value. Each layer then reads the current vector, computes something, and adds the result back. Nothing is overwritten. At the end, the final vector is turned into next-token scores.
>
> A transformer block has two parts. The attention layer (Sections 3.4 and 3.5) moves information from earlier positions into the current one. The MLP layer, a small two-layer network applied to each position separately, expands the vector to four times its size, applies an activation function, and projects it back down.
>
> MLP layers can be read as key-value memories (Geva et al. 2021). Rows of the first matrix act as keys that detect patterns in the residual stream, and columns of the second matrix act as values that write related information. Many factual associations, such as "the Eiffel Tower is in Paris", appear to be stored largely in MLP layers (Meng et al. 2022), though how localized that storage is remains debated.
>
> Because every layer reads from and writes to the same vector, the residual stream is the natural place to look for what a model represents. Section 6 looks there.

**Image.** The standard block diagram: a vertical line for the residual stream, with attention and MLP blocks branching off to the side and adding back in, repeated for three layers, with normalization shown at each read.

**Interactive: "Read the stream".**

- Display: a grid with one row per layer and one column per input position. Each cell shows the token the model would predict if the residual stream at that layer were sent straight to the output (the "logit lens"), colored by probability.
- Controls: prompt menu; tap a cell for the top 10 predictions there and for which component in that layer (attention or MLP) changed the prediction most.
- Try: (1) For "The Eiffel Tower is located in the city of", find the layer where "Paris" becomes the top prediction. (2) Check whether attention or the MLP made that change.
- What to notice: the prediction is built up gradually, by additions to one vector.
- Build: precomputed from GPT-2 small; medium.

**Check.** Can layer 8 use information computed by layer 2? Answer: yes. Layer 2's output was added to the residual stream, and layer 8 reads the residual stream.

**Links.** Forward to 3.7, 6.2, 6.6. References: Elhage et al. (2021); Geva et al. (2021); Meng et al. (2022); Hase et al. (2023), on localization; nostalgebraist (2020), "interpreting GPT: the logit lens".
